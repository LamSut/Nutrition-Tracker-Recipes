## About the Project
The Nutrition Tracker Recipe Application is a Flutter-based mobile app designed for health-conscious users and food enthusiasts. It enables users to explore various foods with detailed nutrient data and create personalized recipes tailored to their dietary goals. Using PocketBase for backend storage, the app ensures seamless data management and real-time access. Whether you want to track nutrients, optimize meals, or discover new recipes, this app provides an intuitive and efficient way to make informed food choices.
